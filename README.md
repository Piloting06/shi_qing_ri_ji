# 拾晴日记 ☀️

> 天气加心情。写下来，发给 Ta。

拾晴日记是一款「天气 × 心情」手账风日记 App：记录每一天的情绪时自动绑定当时的天气，随手制成可分享的手账卡片。用得越久，它越懂你——雨天的心事、晴天的开心、那年今天的自己，都会被温柔地记下来。

**当前版本：v2.13.0+25** ｜ 平台：Android（iOS 工程就绪）

---

## ✨ 核心特色

### 🎴 心情卡片生态（产品灵魂）

- **12 套手账模板**：经典笔记（晨光/夜航/薄荷/绯霞）、晴收集、胶片、车票、火焰、周历、节气限定、贴纸、极简
- **晴收集 · 天气联动**：卡片随当天真实天气自动换肤——晴=向日葵光晕、雨=雨痕玻璃、雪=雾蓝雪花，也可手动指定天气图案
- **心晴签**：基于「天气 × 心情 × 历史」的个性化短语（如"这是你在雨天里写下「平静」的第 8 次"），每张卡都独一无二
- **卡片册**：制作过的卡片自动存档成个人册子，可翻阅、重分享——用得越久越厚，是抄不走的资产
- **那年今日**：首页呈现往年同一天的记录，一键把回忆制成卡片
- **1:1 方图 / 竖版**双比例导出，分享文案预填，可选二维码拉新（`?from=card` 全链路可统计）
- 左右滑动实时切换模板，触感反馈，记住偏好

### 📝 记录体验

- 心情八宫格首屏即达，标签/正文同屏完成，底部内联保存条
- 首页时段问候 + 天气迷你章 + 错落入场动效；天气大卡以细体大数字温度为主视觉，附日出日落
- 8 种心情 × 动态标签，手账纸纹书写区
- 回顾区：7 天连续条、本周记录小结、当日时间线

### 🗺 城迹 · 城市心晴榜

- 全国城市匿名情绪地图：哪座城在说什么
- 最近 7 天「城市心晴榜」横滑榜单（记录数排序 + 城市最常见心情）
- 心情记录自动关联定位城市与天气码，数据越攒越多

### 🌤 天气与定位

- 四层定位：本地缓存 → GPS → IP 定位（服务端透传真实客户端 IP）→ 默认城市
- Open-Meteo 三天预报，服务端聚合缓存
- 每条心情写入时快照天气码，为洞察与年度报告积累数据

### 📮 其他

- **时光胶囊**：写给未来，到期本地通知（Android 14+ 精准闹钟自动降级兼容）+ 邮件提醒
- **轻社交**：手机号加好友、7 天授权看好友心情、心情评论；树洞匿名留言（敏感词过滤）
- **主题系统**：多套主题 + 暗色模式，切换 420ms 平滑过渡

## 🛠 技术栈

| 层 | 技术 |
|---|------|
| 客户端 | Flutter 3.x / Dart，Provider 状态管理 |
| 后端 | Node.js / Express，Helmet + rate-limit + CORS 白名单 |
| 数据库 | SQLite（sql.js）——防抖合并落盘 + 原子 rename，每日双目录自动备份（保留 14 份） |
| 通知 | flutter_local_notifications + timezone（精准闹钟降级策略） |
| 天气 | Open-Meteo；定位 geolocator + IP 定位（X-Forwarded-For 透传） |
| 邮件 | Resend API（验证码 / 胶囊提醒 / 天气反馈） |
| 分享 | share_plus + gal（相册）+ qr_flutter（拉新二维码） |

## 📁 项目结构

```
lib/
  api/          # API 客户端（按域拆分模块）
  constants/    # 常量（心情体系、存储 Key）
  pages/        # 页面（首页/心情/城迹/树洞/友人/胶囊/卡片册…）
  services/     # 本地通知、定位
  stores/       # Provider 状态（App/Theme/Map）
  theme/        # 设计系统（颜色 Token/字体/装饰/纸纹/手绘）
  utils/        # 工具（心情统计、心晴签、节气、天气码）
  widgets/      # 组件（卡片制作器、mood_card/ 12 模板、空状态、动效…）
server/
  routes/       # Express 路由（auth/mood/city/friends/capsule/treehole…）
  db.js         # SQLite：防抖原子落盘 + 每日双备份
  scripts/      # restore.js 一键恢复（恢复前自动留底）
  admin/        # 运营后台静态页
sqrj-landing/   # 官网落地页（Next.js 静态导出）
test/           # 单元测试（心情统计/心晴签/天气码）
```

## 🚀 开始

```bash
# 客户端
flutter pub get
flutter analyze   # 应为 0 issue
flutter test      # 单元测试
flutter run

# 构建
flutter build apk --release --target-platform android-arm64

# 后端
cd server && npm install && node index.js   # 端口 3001
```

### 部署要点

- nginx 反代需透传 `X-Forwarded-For` / `X-Real-IP`（IP 定位与限流依赖）
- Express 需 `app.set('trust proxy', 1)`（已内置）
- 数据库备份目录：`server/backups/` + `DB_BACKUP_DIR_EXTERNAL`（默认 `/root/db_backup`）

## 🔒 隐私原则

> 你的情绪数据只属于你自己。

- 心情/天气数据存于自有服务器，不接入任何第三方分析 SDK
- 好友查看心情需显式授权，授权 7 天自动过期
- 树洞/城墙留言匿名，敏感词过滤
- 卡片册仅存本地设备
