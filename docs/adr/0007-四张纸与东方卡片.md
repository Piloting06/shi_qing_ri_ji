# ADR-0007: 主题合并为四张纸并配来历；分享卡片改为东方一系

日期：2026-11-04 ｜ 状态：Accepted ｜ 决定人：用户（「优化合并几个主题，现在感觉区别不大」+ 四问拍板）

部分取代 [ADR-0006](0006-六张纸与换纸.md) 的「六张纸」一条；深浅三档、换纸墨晕不变。

## 背景

六张纸里四张浅色看起来差不多。用户同时要求：讲纸背后的故事、给情绪价值、融入东方文化；心情卡片全面优化；App 里的技术信息不对外。

## 决定

1. **四张纸，浅二深二，一眼分得开**：素笺（生宣本色）、薛涛笺（桃红小笺，纸色明显偏红）；磁青（磁青纸泥金）、乌金（暖黑，银泥）。暖笺、青笺并入素笺；藕笺升级为薛涛笺；黛笺改名乌金。存储 id 不变（blush / dark），旧值 warm / mint 迁到素笺。单测锁定同深浅两张纸的裱绫色差。
2. **纸的来历**：每张纸一段来历（宋代以前的造纸与用纸典故，只写有出处的常见说法）。从「我」页纸样换纸时，墨晕开后浮出一张小笺竖写来历，约 3 秒自己收，点一下提前收；切深浅不讲故事。
3. **节气小笺**：首页题跋可点，打开这个节气的三候（标出这几天在第几候）、一句白话、一句古诗、下一个节气。节气第一天、还没看过时节气印角上一个朱点。
4. **分享卡片东方一系**：四张纸的「笺」+ 册页、扇面、实寄封、节气、七日；去掉胶片、车票、火焰、贴纸、极简、晴收集、旧周历、旧节气。卡片编辑器重做：编辑项常驻，选项一律签条，落款与日期改中文（含汉字纪年），二维码画进导出图。
5. **信息正式化**：关于页去掉 GitHub、开源许可、技术栈、域名、国标编号、权限代码；写缘起一段；运营主体暂不写。定位来源不出现 GPS / IP 字样。

## 代价

- 选过暖笺 / 青笺的老用户会回到素笺（下次打开即生效，无提示）。
- 卡片册里旧模板做的卡是图片，不受影响；但卡片编辑器里不能再选旧模板。
- 展示字体子集补了〇与竖排标点（+19KB）。
