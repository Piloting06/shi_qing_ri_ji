# ADR-0005: 视觉方向改为「笺谱」：每天一张木版水印笺

日期：2026-11-04 ｜ 状态：Accepted（方向）；展示字体待样张确认；「主题收敛为两套」一条被 [ADR-0006](0006-六张纸与换纸.md) 取代 ｜ 决定人：用户（「可以」认可全部推荐项）

部分取代 [ADR-0004](0004-素笺默认化.md)：深色「夜墨」改「磁青」、老主题下线、展示层字体由思源宋改朱雀仿宋。素笺作为默认设计系统不变。

## 背景

P6–P8 依次修了字体、配色、层级与动态天色，用户仍反馈「整体廉价、没有独特东方韵」。逐屏诊断后归为五条：

1. 骨架是通用模板（白色圆角卡片 + 投影、胶囊底栏、iOS 设置式图标方块、棕色大按钮），东方元素只是贴在上面。代码里 Material 图标 258 处、自绘 8 处；系统转圈、对话框、日历仍在。
2. 没有「物」的质感：纸是平色，天是渐变，山是剪影，印是红框加字。
3. 颜色发浑：深檀棕实底按钮、米色叠米色、莫兰迪心情色。
4. 展示字思源宋是「国风 App 默认款」。
5. 留白没有点景撑起，只是空。

## 备选评估

1. **水墨写意**：屏幕上做不地道就成游戏宣传图或国潮海报；实时渗化成本高。
2. **宋式极简（P6–P8 路线）**：已验证，做不好就是「米色加灰」。
3. **骨架不动只加材质**：解决第 2 条，第 1、3 条仍在。
4. **笺谱·木版水印（选定）**：参照十竹斋笺谱、荣宝斋信笺。版画是平面的，和屏幕天然相容；套色版画能用代码画地道；笺本就是写字寄信的纸，对上「写下来，发给 Ta」。

## 决策

选 4，先做样张（首页 + 心情页）再铺开。要点：

- **材质**：宣纸纹理 `assets/textures/paper.png`（`scripts/gen_paper.py` 生成，可平铺），组件以 DecorationImage 铺、画笔以纹理侵蚀。
- **层级 = 装裱**：L0 裱绫（偏深）/ L1 笺（更亮 + 0.6px 墨线 + 1px 纸厚，圆角 3）/ L2 毛边叠纸（唯一投影）。
- **色**：交互色深檀 → 墨（深色为泥金）；朱砂只给印与钤印；心情八色改国画颜料（藤黄、石绿、花青、胭脂、赭石、淡墨、朱膘、藕荷）。
- **深色**：磁青纸 · 泥金 · 月白。
- **笺头画**：天色改木版套色（刷痕、错版、断续勾线、侵蚀、纸纹）；点景取《芥子园画传》1679 初版线稿（The Met 开放获取 CC0，来源见 `assets/motifs/SOURCES.md`）；右上题跋为公版古诗，按天况 × 季节 × 昼夜 × 节气选，日期命中优先（`lib/data/poems.dart`）。
- **印**：`XqSeal` 重写为刻石印（边框抖动、崩口、印泥斑驳；朱文 / 白文）。
- **组件**：底栏单字「天 · 心 · 城 · 我」，选中为墨色白文小印；保存心情 = 盖印；标签 = 签条；书写区 = 朱丝栏信笺。
- **字体**：展示层用朱雀仿宋子集（OFL-1.1，`scripts/subset_display.py`）；思源宋子集保留作缺字回退与印文。候选霞鹜新致宋（IPA 许可，子集化属衍生程序）只在样张对比，不入库。
- **主题**：收敛为素笺 / 磁青两套，暖笺 / 黛笺 / 青笺 / 藕笺在全量铺开阶段下线。

## 后果

- 收益：东方气质来自骨架与材料而非贴纸；每天的笺随天气、节气、诗句变化，有回访理由。
- 代价：再次推翻 P8 的部分层级手法；安装包增加约 3MB（展示字体 2.3MB、纹理与线稿约 0.3MB）；朱雀仿宋仍是技术预览版。
- 风险与对策：仿宋笔画细，只用于 ≥17px；纹理与版画全部静态缓存，逐帧只画雨雪；诗句只收通行本无争议名句，覆盖由单测锁定。
- **重评触发**：样张真机验收不通过，或用户在两款展示字体中改选。
