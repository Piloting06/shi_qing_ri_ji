# ADR-0006: 主题改为「六张纸」，深浅跟随系统，换纸用墨晕过渡

日期：2026-11-04 ｜ 状态：Accepted ｜ 决定人：用户（「优化其他几个主题」「切换的 UI 和方式很简陋」）

部分取代 [ADR-0005](0005-笺谱方向.md) 的「主题收敛为素笺 / 磁青两套」一条；笺谱方向本身不变。

## 背景

P9 按 ADR-0005 把主题收成两套。用户随后要求把暖笺 / 黛笺 / 青笺 / 藕笺优化回来，并指出切换主题的界面（两个色块）和方式（只能手动、整屏颜色硬跳）简陋。

## 决定

1. **主题 = 纸**。浅色四张：素笺（生宣）、暖笺（竹纸）、青笺（浅碧染笺）、藕笺（藕色染笺）；深色两张：磁青（磁青纸泥金）、黛笺（乌金纸银泥）。纸纹、印、栏线、笺头画全部共用，只换纸色、墨色、印泥。存储 id 沿用旧主题 id（sujian / warm / mint / blush / sujian_dark / dark），老用户的选择能直接对上。
2. **深浅与纸分开**：「跟随系统 / 总是白天 / 总是夜里」三档，浅色、深色各记一张纸。点哪张纸就用哪张；点的纸和当前深浅不同时，顺带把深浅固定过去。
3. **换纸过渡**：换纸那一刻截下旧画面盖在最上层，新纸从点按处以不规则边缘晕开（640ms，先快后慢）；跟随系统自动切换时只淡出；减弱动效时只淡出。不逐帧插值颜色。
4. 颜色从 `ThemeState` 里的 switch 分支改为数据类 `XqPalette`，新增纸 = 加一个常量。
5. 分享卡片的「笺」模板用同一套六张纸，默认取 App 当前那张。

## 代价

- 六张纸 × 对比度都要守住：`test/theme_regression_test.dart` 对每张纸逐项检查（正文 / 次要 / 辅助 / 交互色 / 日期数字 / 印泥 / 错误色在裱绫、笺、凹陷三种底上 ≥4.5，按钮字 ≥4.5，控件边框 ≥3）。
- 换纸时多一张全屏截图（约 10MB 显存，过渡结束即释放）。
