# ADR-0004: 界面默认主题切换为素笺（纸墨），全量而非试点

日期：2026-11-02 ｜ 状态：Accepted ｜ 决定人：用户（明确指示"把这个做为默认"）

## 背景

v2.9 以来 App 的视觉语言（暖金主色、彩色宫格、76 号大数字、光晕）逐步走向"现代多巴胺"，与产品内核（时序、手账、天气×心情）气质持续偏离。用户提出整体转向东方禅意，并提供了完整的素笺设计规范（宣纸 #F4F1E8 / 墨 #26251F / 松烟青 #2F5D56 单一交互色 / 朱砂每屏至多一处 / 夜墨深色），随后补充"江南韵"解读层。

## 备选评估

1. **主题包试点**（AI 最初建议）：素笺作为第四套可选主题，数据验证后再设默认。代价：新旧两套气质长期并存，分裂感延续；验证周期长。
2. **全量默认**（用户选定）：素笺直接设为出厂默认，老主题降为可选。代价：既有用户视觉突变；刚完成的首页 UI（宫格/大卡）降级出首屏，沉没成本弃用。
3. **换 App 名为素笺**：用户否决——拾晴日记保留品牌名，素笺为设计系统与主题名。

## 决策

选 2。实现要点：

- 双主题：`sujian`（宣纸）+ `sujian_dark`（夜墨），走既有 ThemeState/XqTheme 管线；老主题（warm/dark/mint/blush）保留可选作为回退。
- **默认迁移**：新增 `StorageKeys.themeExplicit`；未显式选过主题（存值仍为出厂默认 warm）的用户自动迁到素笺；显式选过 mint/blush/dark 的尊重其选择。
- `main.dart` 的 `darkTheme` 按 isDark 主题路由（否则夜墨会错误落到旧深蓝）。
- 首页按规范彻底减法；手写体保留于内容层（日记正文/卡片），界面文字两层（宋/黑）。
- 江南韵为解读层：烟雨远山插画（山随节气变）、雨天黛蓝（#37566F）色温、帘纹纸纹、水汽感文案；功能词保持现代中文，禁止符号堆砌。

## 后果

- 收益：产品气质与内核统一；设计纪律有明文规范可依；多巴胺元素有序退场。
- 代价：v2.9~v2.9.3 部分首页工作沉没；老用户需一次性适应；自绘图标（1.5px 线性）与宋体子集字体是持续的工程投入。
- **重评触发**：素笺上线后留存/分享率显著下滑时（回退路径：老主题仍在选择器中）。
